# MidgardMaintenance

Plugin Paper de modo manutenção: bloqueia a entrada de jogadores durante manutenções e atualiza a si mesmo por
GitHub Releases.

## Destaques

- Comando `/mmaintenance` para ligar e desligar a manutenção.
- Atualizador automático via GitHub.
- Integração opcional com MMOCore, ReviveMe e rPermadeath.

## Stack

Java 21 · Maven · Paper API

## Como compilar

```bash
mvn package
```
