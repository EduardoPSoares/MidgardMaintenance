# MidgardMaintenance

![Java](https://img.shields.io/badge/Java-21-E76F00?logo=openjdk&logoColor=white)
![Paper](https://img.shields.io/badge/Paper-1.21-2F80ED)
![License](https://img.shields.io/github/license/EduardoPSoares/MidgardMaintenance)

Plugin Paper de modo manutenção: bloqueia a entrada de jogadores durante manutenções e atualiza a si mesmo por
GitHub Releases.

## Destaques

- Comando `/mmaintenance` para ligar e desligar a manutenção.
- Atualizador automático via GitHub.
- Integração opcional com MMOCore, ReviveMe e rPermadeath.

## Stack

Java 21 · Maven · Paper API

## Como compilar

```bash
mvn package
```
